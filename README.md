# MAALUM - Aluminium & Accessoires

**MAALUM** est une plateforme moderne dédiée à la vente d'accessoires aluminium, quincaillerie de menuiserie aluminium, et services sur-mesure (conseil technique, conception et logistique).

---

## 🌟 Fonctionnalités Principales

- 🛍️ **Catalogue d'Accessoires Aluminium** : Découverte des produits et pièces de menuiserie aluminium.
- 📐 **Services Sur-Mesure** : Conseil, expertise technique et solutions personnalisées.
- 🚚 **Logistique & Livraison** : Suivi et livraison rapide des commandes.
- 💬 **Contact Direct** : Intégration WhatsApp et demande de devis instantanée.

---

## 🛠️ Technologies Utilisées

- **Front-end** : React 19, Vite
- **Styling** : CSS Custom Properties / Modern Vanilla CSS
- **Icons** : SVG Vectors

---

## 🚀 Démarrage Rapide

### Prérequis
- [Node.js](https://nodejs.org/) (v18 ou supérieur recommandé)
- `npm` ou `yarn`

### Installation & Lancement

1. **Cloner le projet ou naviguer dans le dossier**
   ```bash
   cd project-minuisrie
   ```

2. **Installer les dépendances**
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement**
   ```bash
   npm run dev
   ```

4. **Accéder à l'application**
   Ouvrez votre navigateur à l'adresse : `http://localhost:5173`

---

## 📦 Scripts Disponibles

- `npm run dev` : Démarre le serveur de développement Vite.
- `npm run build` : Compile l'application pour la production.
- `npm run preview` : Prévisualise le build de production en local.
- `npm run lint` : Exécute ESLint pour vérifier la qualité du code.
